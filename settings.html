连接与游戏

1103 环境资源

将随程序提供的四语卡池和 2011.3.1 禁卡表安装到当前游戏。请先退出游戏；原文件会备份，可一键恢复。

旧裁定脚本

从 301zrg/specials 的 706 目录更新脚本到 expansions/script。游戏运行时先退出游戏，再应用更新。此操作不会改游戏设置或根目录 script。

若旧裁定仍未生效，请在游戏设置中检查“优先扩展脚本”。脚本更新不能保证所有旧录像都可播放。

助手更新

检查 GitHub 上的最新正式版。下载后关闭游戏和助手，将 ZIP 解压覆盖到游戏根目录，并保留 srvprotianti-desktop-data 文件夹。
